# Module Deep-Dive: Resume Tailor Agent & Guardrails (`src/tailor_agent.py`)

## 1. Technical Concepts & Design Patterns

The `tailor_agent.py` module manages context-aware resume alignment and document compilation. It reframes candidate achievements to highlight alignment with target job descriptions while enforcing **anti-hallucination guardrails** and compiling publication-grade PDFs via **Typst**.

### Key Architectural Concepts

#### 1. The STAR Methodology Pattern
Modern technical recruiters and hiring managers favor the STAR framework:
* **Situation:** High-level organizational or technical context.
* **Task:** Explicit engineering challenge or operational requirement.
* **Action:** Concrete technical implementation (tools, algorithms, refactorings).
* **Result:** Quantifiable business impact or latency/throughput improvement.
The agent structures bullets to begin with strong past-tense action verbs (e.g., *"Architected"*, *"Engineered"*, *"Optimized"*), foregrounding target technologies matching the job opening.

#### 2. Metric Conservation Guardrail (Regex AST)
A notorious failure mode of Generative AI in career tools is numerical hallucination: models frequently invent metrics (e.g., changing *"Improved database speed"* to *"Increased throughput by 87% and saved $45,000"*).
CareerPilot AI eliminates this risk by extracting all numerical tokens using a regular expression:
```python
METRIC_REGEX = re.compile(r"(\$?\d+(?:[.,]\d+)?%?|\b\d+\b)")
```
If the tailored text contains *any* numerical metric not present in the candidate's original verified bullets ($\text{TailoredMetrics} \setminus \text{SourceMetrics} \neq \emptyset$), the bullet is automatically rejected and reverted to the verified source text.

#### 3. Typst vs. LaTeX Document Compilation
Traditional automated resume pipelines rely on TeX distributions (such as TeX Live or MacTeX). In production environments, LaTeX introduces severe bottlenecks:
- Multi-gigabyte container image bloat (3GB to 6GB).
- Slow compilation times (2.0 to 8.0 seconds per PDF).
- Brittle escaping errors on special characters (`&`, `%`, `_`, `#`).

CareerPilot AI adopts **Typst**, an open-source systems programming document compiler:
- Sub-50ms native compilation speed.
- Lean binary footprint without multi-gigabyte dependencies.
- Deterministic, readable AST markup syntax.

## 2. Core Classes & Methods

### `ResumeTailorAgent`
* **Location:** `src/tailor_agent.py`
* **Purpose:** STAR formulation, hallucination detection, and Typst code generation.

#### Methods & API

##### `__init__(groq_api_key: Optional[str] = None, model_name: Optional[str] = None)`
* **Inputs:** API credentials and model name.
* **Defaults:** Pulls from `settings.groq_api_key` and `settings.groq_model_name` (`"llama-3.3-70b-versatile"`).

##### `verify_metric_conservation(source_bullets: List[str], tailored_bullet: str) -> bool`
* **Inputs:**
  * `source_bullets` (`List[str]`): Candidate's original verified bullet points.
  * `tailored_bullet` (`str`): Rephrased bullet point generated by the language model.
* **Outputs:** `bool` — `True` if all numbers, percentages, and currencies in the tailored bullet exist in the source; `False` if fabricated metrics are detected.
* **Why it exists:** Provides deterministic mathematical protection against resume fabrication.

##### `_call_groq_star_rephrase(raw_bullet: str, target_role: str, target_skills: List[str]) -> str`
* **Inputs:** Raw bullet point, target job title, and priority skill keywords.
* **Outputs:** Rephrased active STAR sentence.
* **Execution:** Issues a low-temperature (`0.1`) HTTP POST request to Groq's LPU endpoints (`api.groq.com/openai/v1/chat/completions`) with strict word count and metric conservation instructions. Falls back to local synthesis if unavailable.

##### `tailor_experience_local(candidate: CandidateProfile, job: JobPosting) -> TailoredResumePayload`
* **Inputs:** `CandidateProfile` and target `JobPosting`.
* **Outputs:** Structured `TailoredResumePayload` containing tailored professional summary, aligned skill sets, and validated STAR bullet points.

##### `export_to_typst(payload: TailoredResumePayload) -> str`
* **Inputs:** `TailoredResumePayload`.
* **Outputs:** Clean Typst markup string formatted with professional margins, font configurations, and bullet structures ready for execution via `typst compile`.

## 3. Concrete Example & Usage

```python
from src.schemas import CandidateProfile, JobPosting
from src.tailor_agent import ResumeTailorAgent

tailor = ResumeTailorAgent()

# 1. Test Anti-Hallucination Guardrail against metric fabrication
source_bullets = ["Optimized SQL queries and automated data cleaning scripts that improved processing speed by 35%."]

# Case A: Honest rephrasing preserving the original 35% metric
honest_bullet = "Engineered automated SQL queries and ETL scripts, cutting data latency by 35%."
print("Honest Bullet Valid?", tailor.verify_metric_conservation(source_bullets, honest_bullet))
# Output: True

# Case B: LLM hallucination inventing an unearned metric (e.g. 75% or $50k)
fake_bullet = "Architected automated SQL pipelines cutting latency by 75% and saving $50,000 annually."
print("Fabricated Bullet Valid?", tailor.verify_metric_conservation(source_bullets, fake_bullet))
# Output: False (Rejected by guardrail)

# 2. Generate Typst Markup for compilation
from src.schemas import TailoredResumePayload, TailoredExperience, STARBullet

payload = TailoredResumePayload(
    candidate_name="Alex Mercer",
    target_job_title="Data Scientist",
    summary="Results-driven Data Scientist specializing in predictive modeling and scalable SQL pipelines.",
    experiences=[
        TailoredExperience(
            company="DataCorp",
            role="Data Scientist",
            source_bullets=source_bullets,
            tailored_bullets=[
                STARBullet(
                    situation_and_task="High transaction volume causing query delays.",
                    action="Wrote indexed SQL JOIN queries and automated data validation scripts.",
                    result="Reduced ETL processing latency by 35%.",
                    final_bullet="Engineered automated SQL queries and ETL scripts, cutting data latency by 35%."
                )
            ]
        )
    ],
    aligned_skills=["Python", "SQL", "Pandas", "Scikit-Learn"]
)

typst_code = tailor.export_to_typst(payload)
print(f"Generated Typst Code Preview:\n{typst_code[:220]}...")
```
